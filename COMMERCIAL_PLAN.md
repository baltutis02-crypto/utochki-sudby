# Уточки судьбы — commercial v1

## Цель
Превратить статичную страницу колоды в коммерческий сайт бренда:
- персональные разборы (Натальная карта, Саджу, затем комбо и новые продукты);
- онлайн-оплата через интернет-эквайринг Точка Банка;
- единый личный кабинет покупателя;
- отдельный кабинет администратора;
- история и статусы заказов;
- отдельный чат внутри каждого заказа;
- выдача готового PDF;
- физические продукты с переходом на Wildberries;
- mobile-first интерфейс и PWA.

## Логика кабинетов
### Клиент
Один личный кабинет на весь аккаунт:
- все собственные заказы;
- статус каждого заказа;
- отдельный чат с Настей внутри заказа;
- готовый PDF и история файлов;
- новый заказ без создания нового аккаунта.

### Администратор
Отдельный закрытый кабинет:
- входящие новые заявки;
- очередь заказов и статусы;
- карточка клиента и данные, переданные для разбора;
- отдельный диалог с каждым заказчиком по конкретному заказу;
- загрузка готового PDF и смена статуса;
- доступ только для роли admin.
